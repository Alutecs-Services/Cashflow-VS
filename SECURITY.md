# Reportar un problema de seguridad

Si detecta un fallo de seguridad en CashFlow Manager, escríbanos antes de divulgarlo:

**soporte@alutecs.com**

Indique la versión de la aplicación (aparece en **Configuración → Acerca de**), qué sistema
usa y cómo reproducir el problema. Respondemos y, si procede, publicamos una versión
corregida.

Le pedimos que no publique el detalle hasta que la corrección esté disponible, para no
exponer a quienes todavía no han actualizado.

## Versiones con soporte

Se da soporte a la última versión publicada en este repositorio. Las versiones anteriores
se corrigen actualizando a la más reciente.
