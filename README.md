# CashFlow Manager

Descargas oficiales de **CashFlow Manager**, el sistema de control de caja de
**ALUTECS SERVICES**.

## Descargar

**[Descargar la última versión](../../releases/latest)**

El archivo que debe descargar es el que termina en `setup.exe`.

## Qué es

CashFlow Manager lleva el control del efectivo de un negocio: registra lo que entra y lo
que sale, cuadra cada turno de caja, administra la caja chica y genera los reportes del
periodo. Funciona en una sola computadora o en varias conectadas entre sí, compartiendo la
misma información.

- Apertura y cierre de caja por cajero, con cortes parciales y arqueo.
- Entradas y salidas con método de pago, categorías, anulaciones y devoluciones.
- Caja chica con fondo asignado, vales de gasto, reposiciones y gastos fijos.
- Reportes diarios y por periodo, imprimibles y exportables a Excel.
- Tickets en impresora térmica, apertura de la gaveta y envío por WhatsApp.
- Copias de seguridad de toda la información.

## Requisitos

- Windows 10 o Windows 11 (64 bits).
- Conexión a internet durante la instalación y para activar la licencia.
- No hace falta instalar nada más: la propia aplicación instala el servidor de base de
  datos si su computadora no lo tiene.

## Instalación

1. Descargue el archivo `setup.exe` de la última versión.
2. Ejecútelo. No pide permisos de administrador para instalarse.
3. Si Windows muestra un aviso de **SmartScreen**, elija *Más información* y luego
   *Ejecutar de todas formas*.
4. Al abrir la aplicación por primera vez, indique si esta computadora guardará los datos o
   si se conectará a otra que ya los tiene, y active su licencia con el código que le
   entregamos. También puede solicitar un periodo de prueba.

Si ya tenía instalada una versión anterior, el instalador la retira solo. **Su información
no se toca.**
